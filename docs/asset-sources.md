# Asset Sources

- 3D dice runtime assets were copied from the adjacent Moonvault project, which uses `@3d-dice/dice-box`.
- Card visuals are local SVG/CSS card faces designed for this toolbox. Public-domain reference decks were checked before implementation:
  - FreeSVG/OpenClipart deck of cards: https://freesvg.org/deck-of-cards
  - Adrian Kennard public-domain SVG playing cards: https://www.me.uk/cards/
  - Wikimedia Commons `Svg-cards-2.0.svg`: https://commons.wikimedia.org/wiki/File:Svg-cards-2.0.svg
